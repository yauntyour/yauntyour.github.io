C++ Standard Library List

C++标准库列表

Yauntyours·2026 年 10 月 12 日·1440 字·阅读 4 分钟

截至 C++26（2026 年 3 月已定稿），标准库的组件非常庞大。下面按功能类别整理了一份核心标准库组件表格，覆盖从 C++11 到 C++26 的主要头文件及其作用，并附上常见用法示例。

一、语言支持与基础工具

头文件主要组件作用常见用法
<cstddef>size_t, nullptr_t, byte基础类型定义size_t n = v.size();
<cstdint>int32_t, uint64_t 等固定宽度整数类型int32_t x = 42;
<type_traits>is_integral_v, enable_if_t编译期类型查询与变换static_assert(std::is_integral_v<int>);
<concepts>std::integral, std::floating_point概念库（C++20）template<std::integral T> T sum(T a, T b);
<coroutine>coroutine_handle, suspend_always协程底层支持（C++20）配合 std::generator 使用
<source_location>source_location::current()源码位置信息（C++20）auto loc = std::source_location::current();
<version>特性测试宏检查库实现状态（C++20）#if __cpp_lib_generator >= 202207L
<any>std::any类型安全的任意值容器（C++17）std::any a = 42; a = std::string("hi");
<optional>std::optional<T>可能为空的值的封装（C++17）std::optional<int> o = f(); if (o) use(*o);
<variant>std::variant<Ts...>类型安全的联合体（C++17）std::variant<int,string> v = 1;
<tuple>std::tuple, std::get异构值集合auto t = std::make_tuple(1, "a");
<utility>std::move, std::forward, std::pair移动语义与转发auto p = std::make_pair(1, 2);
<bit>std::bit_cast, std::popcount位操作（C++20）auto n = std::popcount(0b1011u);
<expected>std::expected<T,E>值或错误的封装（C++23）std::expected<int,string> r = parse(s);
<print>std::print, std::println格式化输出（C++23）std::println("Hello, {}!", name);
<format>std::format类型安全格式化（C++20）auto s = std::format("{:.2f}", 3.14);

std::expected 是 C++23 引入的标准错误处理方式，可以在不使用异常的情况下返回“值或错误”。

二、容器库

头文件主要组件作用常见用法
<array>std::array<T,N>固定大小数组（C++11）std::array<int,3> a = {1,2,3};
<vector>std::vector<T>动态数组std::vector<int> v{1,2,3}; v.push_back(4);
<list>std::list<T>双向链表std::list<int> l = {1,2,3}; l.push_front(0);
<forward_list>std::forward_list<T>单向链表（C++11）std::forward_list<int> fl = {1,2,3};
<deque>std::deque<T>双端队列std::deque<int> d; d.push_back(1); d.push_front(0);
<map>std::map<K,V>有序键值对（红黑树）std::map<string,int> m; m["a"] = 1;
<set>std::set<T>有序唯一集合std::set<int> s = {3,1,2};
<unordered_map>std::unordered_map<K,V>哈希键值对（C++11）std::unordered_map<string,int> um;
<unordered_set>std::unordered_set<T>哈希集合（C++11）std::unordered_set<int> us = {1,2,3};
<stack>std::stack<T>LIFO 栈适配器std::stack<int> st; st.push(1);
<queue>std::queue<T>FIFO 队列适配器std::queue<int> q; q.push(1);
<flat_map>std::flat_map<K,V>连续内存映射（C++23）std::flat_map<int,string> fm; fm[1]="a";
<flat_set>std::flat_set<T>连续内存集合（C++23）std::flat_set<int> fs = {3,1,2};
<inplace_vector>std::inplace_vector<T,N>固定容量栈上向量（C++26）std::inplace_vector<int,10> iv; iv.push_back(1);
<hive>std::hive<T>稳定地址容器（C++26）适合频繁插入删除、需地址稳定的场景

用法示例（std::vector + std::map） ：

vector 和 map 是 C++ 最常用的容器，分别适合动态数组和键值对场景。

C++23 新增容器说明：std::flat_map 和 std::flat_set 将元素存储在连续内存中，提供更好的缓存性能。C++26 的 std::inplace_vector 提供固定容量、栈上分配的序列，避免堆分配开销。

三、算法与迭代器

头文件主要组件作用常见用法
<algorithm>sort, find, count, transform通用算法std::sort(v.begin(), v.end());
<numeric>accumulate, reduce, iota数值算法int s = std::accumulate(v.begin(), v.end(), 0);
<ranges>views::filter, views::transform, ranges::to范围库（C++20/23）v | views::filter(pred) | views::take(5)
<iterator>begin, end, advance, next迭代器工具auto it = std::next(v.begin(), 2);
<execution>std::execution::par并行执行策略（C++17）std::sort(std::execution::par, v.begin(), v.end());

用法示例（std::ranges + std::views） ：

范围库让算法可以管道式组合，std::ranges::to（C++23）可将惰性视图直接转为具体容器。

四、内存管理

头文件主要组件作用常见用法
<memory>unique_ptr, shared_ptr, weak_ptr智能指针auto p = std::make_unique<Foo>();
<memory_resource>pmr::vector, memory_resource多态分配器（C++17）std::pmr::vector<int> v(&pool);
<scoped_allocator>scoped_allocator_adaptor嵌套分配器（C++11）容器嵌套时的分配器传播

智能指针对比：

智能指针所有权引用计数适用场景
unique_ptr独占无独占资源，性能最优
shared_ptr共享有多对象共享同一资源
weak_ptr不拥有不参与计数观测共享对象、打破循环引用

智能指针是 RAII 原则在指针管理上的应用，自动管理资源生命周期，避免内存泄漏和悬空指针。

五、字符串与文本处理

头文件主要组件作用常见用法
<string>std::string, std::to_string动态字符串std::string s = "hello"; s += " world";
<string_view>std::string_view非拥有字符串视图（C++17）void f(std::string_view sv);
<charconv>std::from_chars, std::to_chars高效数字转换（C++17）std::from_chars(s.data(), s.data()+s.size(), x);
<format>std::format格式化字符串（C++20）std::format("{} = {:.2f}", name, val);
<regex>std::regex, std::smatch正则表达式（C++11）std::regex re(R"(\d+)");
<text_encoding>std::text_encoding编码检测（C++26）识别和转换字符编码

六、并发与并行

头文件主要组件作用常见用法
<thread>std::thread, std::jthread线程管理（jthread C++20）std::jthread t([]{ work(); });
<mutex>std::mutex, lock_guard, scoped_lock互斥量std::lock_guard lk(mtx);
<atomic>std::atomic<T>原子操作std::atomic<int> counter{0}; counter++;
<condition_variable>std::condition_variable条件变量cv.wait(lk, []{ return ready; });
<future>std::future, std::promise, std::async异步任务auto f = std::async([]{ return 42; });
<barrier>std::barrier线程屏障（C++20）std::barrier sync(4); sync.arrive_and_wait();
<latch>std::latch一次性倒计时（C++20）std::latch l(4); l.count_down();
<semaphore>std::counting_semaphore信号量（C++20）std::counting_semaphore sem(3);
<execution>std::execution::sender/receiver统一异步框架（C++26）结构化并发，避免数据竞争
<simd>std::simd数据并行（C++26）向量化运算

C++26 std::execution（Senders/Receivers） ：这是 C++26 的旗舰并发特性，提供统一的异步执行框架。Senders 描述异步操作，Receivers 接收结果，通过 connect 连接后由 start 启动。

该框架支持结构化并发，从构造上避免数据竞争和死锁。

七、数值计算

头文件主要组件作用常见用法
<cmath>std::sqrt, std::sin, std::pow数学函数double r = std::sqrt(2.0);
<complex>std::complex<T>复数类型std::complex<double> z(1, 2);
<random>std::mt19937, uniform_int_distribution随机数生成std::mt19937 gen{std::random_device{}()};
<ratio>std::ratio<1,1000>编译期有理数（C++11）using ms = std::ratio<1,1000>;
<numbers>std::numbers::pi数学常量（C++20）double area = std::numbers::pi * r * r;
<bit>std::popcount, std::bit_width位操作（C++20）auto n = std::popcount(x);
<linalg>std::linalg::dot, matrix_product基础线性代数（C++26）BLAS 风格线性代数算法

组件标准作用一句话用法
